# Example: Vietnam Maritime University (vimaru.edu.vn)
Real build used to derive this skill: theme `vimaru`, navy brand colors, hero slider of 6 real banners,
quick links, news/notice/event/admission sections pulled from the news module, 16 faculties, 28 real
articles + 6 about pages, all with source links. Files here are copies of that theme
(header/footer tpl, custom.css/js, config.ini, theme.php homepage snippet). Paths reference
`uploads/news/vimaru/...` which must be shipped with the theme. Use as a pattern, not as content.
